01 · Como ler

Comandos usam verbo no imperativo/ação requerida; eventos descrevem o fato ocorrido no passado. “Contexto” é limite de linguagem proposto no documento 08. As formas táticas sem acentos (OrdemDeServico, ItemEstoque, Orcamento) referem os mesmos conceitos de negócio, sem impor classes ou APIs.

Precedência documental: PDF oficial para requisitos; decisões D-00 a D-16 para cenários resolvidos; material da disciplina para a notação; páginas 03–08 para os fluxos. O HTML/board originais contêm propostas anteriores, não revogam as decisões aprovadas. Exemplos abaixo descrevem comportamento, não contrato técnico.

02 · Glossário final

Os termos “serviço”, “item”, “identidade”, “reserva” e “aprovação” recebem qualificador para impedir que conceitos de contextos distintos sejam tratados como um único objeto.
